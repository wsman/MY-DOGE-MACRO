## 🔧 技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| API 客户端 | fetch + 自定义 Hook | 轻量，Zustand 集成 |
| WebSocket | 原生 WebSocket | 已有后端实现 |
| 路由 | React Router v6 | 标准选择 |
| Markdown 渲染 | react-markdown | 研报展示 |
| 通知 | Tauri Notification API | 原生体验 |
| 数据库 | SQLite (开发) → PostgreSQL (生产) | 渐进式 |
