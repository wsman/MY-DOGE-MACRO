## Overview

Reference document for the modular architecture migration from v1.5.0 to v1.6.0 of the MY-DOGE-MACRO system.

This document provides a structured reference to the complete architecture documentation, which describes the transition from traditional monolithic structure to a modular monorepo architecture.

## Key Content Summary

### Architecture Design Principles
- **Single Responsibility**: Clear separation of concerns between layers
- **Dependency Inversion**: High-level modules don't depend on low-level implementations
- **Clear Boundaries**: Well-defined interfaces between modules
- **Progressive Migration**: Gradual transition without breaking existing functionality

### Architecture Layers
1. **Applications Layer** (`apps/`): Runnable applications (desktop app, API services)
2. **Libraries Layer** (`libs/`): Reusable code libraries (quant engine, design system, common utilities)
3. **Infrastructure Layer** (`infrastructure/`): Development and operational infrastructure
4. **Data & Config Layer** (`config/`, `data/`): Configuration and data storage

### Migration Status

| Component | Old Path | New Path | Status | Priority |
|-----------|----------|----------|--------|----------|
| **Design System** | `client/src/design-system/` | `libs/design-system/` | ✅ Complete | - |
| **Frontend App** | `client/` | `apps/desktop/` | 🔄 In Progress | P0 |
| **Backend API** | `server/` | `apps/api/` | 📅 Planned | P0 |
| **Quant Engine** | `engine/` | `libs/quant-engine/` | 📅 Planned | P1 |
| **CDD Tools** | `scripts/` | `infrastructure/cdd/tools/` | 📅 Planned | P1 |

### Module Dependencies
```
apps/desktop/ → libs/design-system/ → (React + TypeScript)
            ↘ libs/common/          → (Shared types)
            
apps/api/     → libs/quant-engine/  → (pandas, numpy, scipy)
            ↘ libs/common/          → (Shared utilities)
```

## Development Setup

### TypeScript Path Mapping
```json
// tsconfig.json (apps/desktop/)
{
  "compilerOptions": {
    "paths": {
      "@design-system/*": ["../../libs/design-system/*"],
      "@libs/*": ["../../libs/*"],
      "@apps/*": ["./src/*"]
    }
  }
}
```

### Python Environment Setup
```bash
# Install quant engine dependencies
cd libs/quant-engine
pip install -r requirements.txt

# Install in development mode
pip install -e .
```

## Architecture Benefits

1. **Maintainability**: Clear module boundaries reduce cognitive load
2. **Testability**: Independent modules facilitate unit testing
3. **Reusability**: Shared libraries reduce code duplication
4. **Scalability**: New features can be added as independent modules
5. **AI Agent Friendly**: Standardized interfaces facilitate AI understanding and operation
